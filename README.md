# Academic Personal Website

A simple static academic website ready to publish with GitHub Pages.

## Files

- `index.html` - Home page with bio and sidebar
- `publications.html` - Publications page
- `education.html` - Education page
- `contact.html` - Contact page
- `styles.css` - Website styling
- `script.js` - Mobile navigation and footer year
- `assets/profile-placeholder.svg` - Placeholder profile image

## How to customize

1. Replace `Dr. Your Name` with your real name in all HTML files.
2. Replace `your.email@example.com` with your email address.
3. Update your address, biography, research areas, education, and publications.
4. Replace `assets/profile-placeholder.svg` with your own photo, for example `profile.jpg`, and update the image path in `index.html`.

## Publish using GitHub Pages

1. Create a new GitHub repository, for example `academic-website`.
2. Upload all files in this folder to the repository.
3. Go to repository `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and root folder `/`.
6. Save. GitHub will provide your website URL.

## Local preview

Open `index.html` in a browser.
